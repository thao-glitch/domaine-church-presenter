Full-screen live output for worship services — hymns, Bibles and announcements in one lightweight program.

Made for church services

Live output window

A full-screen presentation window for the projector, plus a separate controller window to operate it.

Per-slide backgrounds

Each slide can use its own background image, or plain themed slides.

Image slides

Display a photo or graphic full-frame without any text.

Per-slide audio

Attach a song or track to any slide; it plays when the slide appears.

Text color & shadow

Colorize slide text and add a soft shadow for readability on any background.

Lower-third mode

Place announcements or references in a lower-third band over the image.

Margins

Add a safe-area margin around slide text.

Loop & timing

Loop a set, set a per-slide duration, and auto-advance during the service.

Go to slide

Jump straight to any slide from the controller.

Alert messages

Scroll a notice across the bottom of the live output.

Built-in Bible

Download Bibles in many languages and both testaments directly in the app.

Public-domain hymns

Bundled hymn books, ready to project.

How it works

1. Write your slides

Slides are plain .txt files in a slides folder, one file per set, in any language.

2. Load a set

Pick the set from the controller window. The live window shows it on the projector.

3. Run the service

Advance with the buttons or the keyboard: Space/N next, P prev, A auto, +/- speed, R restart, F11 fullscreen.
